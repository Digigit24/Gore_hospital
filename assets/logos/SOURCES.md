# Partner logo sources

Logos for the Cashless Facility section (`assets/js/cashless-data.js`).
Every file here was taken from the company's own website: the logo shown in
the site header, or the organisation logo the site itself declares. Where the
image file is hosted on the company's asset/CDN domain, both the page and the
file URL are listed. No image search, Wikipedia or third-party logo sites were
used.

Processing: converted to PNG, transparent background kept, empty margins
trimmed, scaled down to max 400px wide (never scaled up). Files marked
"Cropped from" had extra material (badges, certification text) cut away;
nothing was redrawn. Renamed companies use the current brand logo from the
company's own (redirected) site.

Collected: 2026-11-08. Logo files are company trademarks, used to identify
empanelled partners.
